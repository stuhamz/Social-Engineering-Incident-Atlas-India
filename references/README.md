# References

The `references/` directory records source provenance and candidate screening.

## Current v0.3.0 snapshot

- `sources.csv`: **243** registered public sources
- `screening_log.csv`: **319** logged candidates

Screening decisions:

- include: 233
- exclude: 67
- duplicate: 12
- pending: 7

Source URLs identify the public material used for coding. The Atlas does not republish the underlying source documents.

Candidate logging is part of the audit trail. A candidate can remain excluded, duplicate, or pending without receiving a case ID.
