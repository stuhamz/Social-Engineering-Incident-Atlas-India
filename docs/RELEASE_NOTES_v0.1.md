# v0.1 Release Notes

## Release

**Social Engineering Incident Atlas India v0.1**

This release contains the first ten reviewed records used to test the project methodology.

## Included

- 10 incident-level records
- 16 registered public sources
- 10 screening-log records
- 10 narrative reconstruction notes
- controlled vocabularies
- machine-readable JSON schema
- inclusion/exclusion and sampling methodology
- evidence and attribution frameworks
- validation scripts
- pre-publication release audit

## Scope

The ten cases were selected for diversity and methodology testing.

They are **not** a representative sample and should not be used to estimate prevalence, average loss, state rankings, or national patterns.

## Audit correction

The pre-publication audit corrected the SEIAI-0002 distinct beneficiary-account count from 8 to 7 and made several conservative coding adjustments to cross-border, reconnaissance, and credential-compromise fields.

See `docs/v0.1_release_audit.md`.
