# v0.1.3 Release Notes

The Social Engineering Incident Atlas India now contains **40 reviewed incidents** and **116 reviewed actor-role records**.

The ten new cases were selected to broaden the validation corpus rather than maximize raw case count. The batch adds BEC, bank/KYC impersonation, social-media impersonation, customer-support fraud, family impersonation and sextortion, and includes final/appellate consumer, commercial and criminal judgments alongside bail/procedural sources.

The v0.1.2 actor schema is unchanged. New cases were coded directly into both incident and actor layers.

This release remains non-representative and should not be used for national prevalence estimates.

**Research principle:** Reconstruct broadly. Attribute conservatively.
