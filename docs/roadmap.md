# Roadmap

## v0.1.0
- establish the incident-level schema
- code and audit 10 deliberately diverse methodology-pilot cases
- test controlled vocabularies and attribution rules

## v0.1.1
- define and execute a versioned retrieval protocol
- expand to 30 reviewed incidents
- preserve excluded, duplicate, and deferred candidates in the screening log
- run second-pass source, coding, procedural-posture, and privacy audit
- stress-test the schema before larger collection

## Pre-v0.2 schema review
- identify persistently unavailable fields
- decide whether actor-level records are needed
- decide whether source-claim records are needed
- review category overlap and attribution consistency
- quantify source-stage and geographic retrieval bias

## v0.2
- expand to approximately 50 reviewed incidents under the revised protocol
- introduce partial independent double-coding
- publish a descriptive data-quality report
- begin limited descriptive analysis while preserving non-representativeness caveats

## v0.3
- approximately 100 cases
- first reproducible descriptive analysis
- evidence/attribution visualisations
- prepare research-paper questions

## Later
- automated source discovery, not automated factual coding
- cross-state and temporal work where the sampling design supports it
- CaseTrace educational case generation from suitable public records
