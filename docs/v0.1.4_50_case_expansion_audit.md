# v0.1.4 50-Case Expansion Audit

## Scope

v0.1.4 expands the Atlas from 40 to 50 reviewed incident records while retaining the v0.1.2 actor-role schema without breaking changes.

The 41–50 batch was selected to improve **category, geography, source-stage and evidentiary diversity**, not to estimate prevalence.

## Audit decisions

1. **No schema change was required.** The existing actor-role model represented all ten new cases without adding `source_claims.csv` or new actor fields.
2. **Negative attribution is retained where analytically useful.** SEIAI-0041 and SEIAI-0043 show that an accused/associated person can be present in a case while the evidence fails to support the alleged conduct.
3. **Settlement/quashing is not guilt adjudication.** SEIAI-0048 is coded from the complaint/prosecution narrative while the compromise-based closure is preserved as procedural posture.
4. **Consumer liability is not offender attribution.** SEIAI-0042, 0044 and 0045 reconstruct the attack without manufacturing attacker identity from banking adjudication.
5. **No prevalence claims.** Category counts are a property of the purposive corpus and retrieval design.

## Validation

Both structural validators are required to return zero errors and zero warnings before release. A privacy scan is also run over researcher-created public files for phone-number, bank-account and email-like patterns.
