# v0.1 Ten-Case Review Checklist

After 10 cases, answer:

- [ ] Which fields were unavailable in 8 or more cases?
- [ ] Which fields required repeated subjective interpretation?
- [ ] Which controlled values overlapped?
- [ ] Which recurring mechanisms were missing from the taxonomy?
- [ ] Which evidence categories were missing?
- [ ] Were source stages consistently recorded?
- [ ] Did any case accidentally convert allegations into facts?
- [ ] Could attribution strength be applied consistently?
- [ ] Were alternative explanations recorded where appropriate?
- [ ] Did the screening log retain excluded and duplicate candidates?
- [ ] Are the 10 cases diverse enough to test the schema?
- [ ] Is any planned analysis being overclaimed from a purposive pilot sample?
